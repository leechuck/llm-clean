## Rigidity — Essentiality of Class Membership

Classify a class as **+R** when every instance has that class essentially: the individual could not exist as the same individual without being that kind of thing. Classify it as **~R** when every instance has the class only contingently: each instance could exist as the same individual without that class, as with roles, phases, statuses, or temporary conditions. Classify it as **-R** only for the mixed, semi-rigid case where some instances have the class essentially and others have it contingently. Report the strongest applicable value: if all instances are contingent, use **~R**, not **-R**. Rigidity concerns whether the same individual could exist without the property, not whether the property is important, currently true, dependent on something else, or merely irreversible over time.

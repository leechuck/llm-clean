# Rigidity (R)

A property is **essential** to an individual when that individual **could not exist without it** — not "would be different without it," but could not exist at all. The question is always about a particular individual: take one instance, imagine it losing the property, and ask whether *the thing itself* survives.

Three qualifications:

1. **Modal, not temporal.** Ask "could this individual exist without the property?" — at any time, past or future, or in any counterfactual situation. Never "could it lose the property going forward." Every adult was once a child, which shows the individual can exist without being an adult, so *Adult* is anti-rigid despite being irreversible. The same holds for *Widow*, *Graduate*, *Ex-Employee*.
2. **De re, not de dicto.** "Anything that is an X is necessarily an X" is trivially true of every class and settles nothing. So is universal attribution: all swans are birds, but that is a fact about swans, not about rigidity.
3. **Report the strongest value.** `~R` entails `−R`, so the three values are not a partition. Reserve `−R` for the genuinely mixed case and label anything anti-rigid `~R`.

**`+R` — rigid.** No instance can lose the property and continue to exist; losing it *is* ceasing to be: *Person*, *Statue* (squash it and the statue is gone, though the clay remains), *Amount of Matter*, *Organism*, *Event*, *Number*, *Hole*.

**`~R` — anti-rigid.** *Every* instance is able to exist without the property; none holds it essentially: *Student*, *Employee*, *Passenger*, *Tenant* (roles), *Child*, *Adult*, *Caterpillar*, *Butterfly* (phases).

**`−R` — semi-rigid.** The mixed case: **some** instances hold the property essentially, **others** contingently. Use it only when you can name an instance of each kind: *Weapon* (a sword essentially, a rock picked up in a fight contingently), *Hard* (a diamond vs. cooled wax), or an abstraction unioning a rigid class with an anti-rigid one.

**Test:** when the property is lost, is there a natural noun for what remains, and is it the *same individual*? Lose *Student* and you have a person → `~R`. Lose *Statue* and you have clay but no statue → `+R`. If you are reaching for `−R` and cannot name an instance that holds the property **essentially**, the answer is `~R`.

Record the survivor (or, for `−R`, the essential-holder) alongside the label. Note that `+R` is not inherited downward — *Student* under *Person* is correct — but `~R` propagates strictly downward, and a `~R` class subsuming a `+R` class is a violation, not a judgment call.

# Instruction: Evaluating OntoClean's Rigidity (R) Metaproperty

Evaluate the **Rigidity** metaproperty by determining if belonging to a class is essential to the very existence of its instances. The question is always modal and about survival: if an instance were to lose this property, would the individual entity itself cease to exist? 

*Important Convention:* Always report the **strongest** true value. `~R` entails `-R`; if a class is anti-rigid, it must be labeled `~R`, not `-R`. Use `-R` only for genuinely mixed (semi-rigid) cases.

### +R (Rigid)
Assign **+R** if **no instance** can lose the property and continue to exist. The property defines what the thing essentially is; losing the property is identical to the entity ceasing to be.
*   *Test:* If the property is lost, is there a natural noun for what remains? If the only thing left is different matter or a corpse, it is `+R`.
*   *Examples:* Person, Statue, Amount of Matter, Organism, Hole.

### ~R (Anti-Rigid)
Assign **~R** if **every instance** could logically exist without the property. No instance holds it essentially. These are typically temporary roles, jobs, statuses, or life phases.
*   *Note on Irreversibility:* The test is about whether the individual *could* exist without it in any context (past, future, or counterfactual). A *Widow* or *Adult* cannot stop being one going forward, but they existed beforehand without the property. Therefore, they are `~R`.
*   *Test:* If the property is lost, what remains? If the answer is "the same person/insect/entity," it is `~R`.
*   *Examples:* Student (leaves a person), Caterpillar (leaves the same insect), Employee, Passenger, Adult, Widow.

### -R (Semi-Rigid)
Assign **-R** only for the mixed case: **some** instances hold the property essentially, while **others** hold it contingently. The class contains both kinds. 
*   *Guardrail:* You must be able to name an instance that holds the property essentially and one that holds it contingently. If you cannot name an essential holder, the answer is `~R`.
*   *Examples:* Weapon (a sword is essentially a weapon; a rock picked up in a fight is contingently a weapon), Hard (a diamond is essentially hard; cooled wax is contingently hard).
